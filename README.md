# vscodeとの連携において
Nドライブなどでプレビューを行う場合、viteのwatchなどでエラーが発生することがある。
その場合、**"vite.config.js"** または **"vite.config.ts"**に
```
import { defineConfig } from 'vite'

export default defineConfig({
  server: {
    watch: {
      usePolling: true,
    },
  },
})
```
を入力する
